# Personal Portfolio Website

A responsive personal portfolio website designed and developed to showcase my professional profile, technical skills, services, certifications, and projects in Data Analysis and Full-Stack Web Development.

## Project Description

Designed and developed a responsive personal portfolio website to showcase my professional profile, technical skills, services, certifications, and data analysis projects. The website integrates interactive UI components, project galleries, external project links, video presentations, CV download, and direct contact options.

## My Role

Designed and developed the website from scratch, structured the content into reusable React components, implemented responsive layouts and interactive animations, and integrated external assets and links.

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- Framer Motion
- Lucide React
- HTML5
- CSS3

## Key Features

- Responsive and modern interface
- Reusable React components
- Smooth animations and interactive UI
- Projects with images and external links
- Project video presentations through external links
- CV download and LinkedIn integration
- WhatsApp and email contact options
- Certifications section with direct certificate access
- Separate navigation for portfolio sections
- Hosted online using Vercel

## Project Sections

- About
- Education & Experience
- Services
- Skills
- Projects
- Certifications
- Client Feedback
- Contact

## Deployment

The website is hosted online using Vercel.

## Result

A professional, responsive portfolio website that provides a clear and interactive presentation of my technical background, projects, services, certifications, and professional profile.
